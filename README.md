# PJ Channel Customer Value Capstone

Public / school-safe capstone package for the Permanent Jewelry channel customer value analysis.

## Project Objective

This project evaluates which acquisition/source channels appear to bring higher-value Permanent Jewelry customers. The goal is to compare channel quality using customer value and retention behavior, not only first-order activity or aggregate traffic.

## Research Question

Which acquisition/source channels appear to bring higher-value Permanent Jewelry customers when measured by 12-month customer revenue, repeat purchase behavior, and follow-on consumables activity?

## Public-Safe Scope

This public repository contains only school-safe final deliverables and documentation. Raw exports, customer-level processed datasets, Tableau workbook files, validation scratch files, and unrelated internal files are intentionally excluded.

The analysis was performed locally using private source exports from Shopify, HubSpot, Salesforce, and GA4. Public-facing materials use aggregate findings only.

## Headline Findings

Headline-eligible channels:

- Direct / Owned
- Paid Search
- Organic Search

Aggregate KPI summary:

| Channel | Customers | Avg 12M Revenue | Repeat Rate | Follow-On Consumables Rate |
| --- | ---: | ---: | ---: | ---: |
| Direct / Owned | 139 | $1,101.06 | 30.00% | 15.00% |
| Paid Search | 89 | $1,455.22 | 42.70% | 21.35% |
| Organic Search | 70 | $1,338.89 | 37.14% | 22.86% |

Paid Search showed the strongest average 12-month revenue and repeat purchase rate among headline channels. Organic Search showed the strongest follow-on consumables rate. Direct / Owned had the largest headline-channel sample size.

These findings are directional and should be paired with acquisition cost data before making final profitability recommendations.
